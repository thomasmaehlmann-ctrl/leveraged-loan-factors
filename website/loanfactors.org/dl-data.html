OpenDL Europe

Release v–, return quarters – to –.

Version 2026.12.1 corrects the currency treatment, the weighting and the linking of positions of version 2026.12; the main index changes from 9.91% to 9.88% p.a., the value-weighted index from 9.54% to 9.09% p.a. Details in the release notes on Zenodo.

Example

import pandas as pd
r = pd.read_csv("dl_index_returns.csv", parse_dates=["date"])
main = r.query("index == 'ew_managers'").set_index("date")["total"]
print((1 + main).prod() ** (4 / len(main)) - 1)   # annualized return
