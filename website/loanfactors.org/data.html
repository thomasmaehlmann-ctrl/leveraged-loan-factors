Finding a series

Each row in factor_returns.csv is one monthly return, identified by these columns:

ColumnValues
factorvalue, momentum, illiquidity, quality, low_risk, carry, ivol, bab, combi, market
portfolioQ1 to Q5, LS (long-short), BM (benchmark), MKT (market index)
weightingew, vw, vw_cap
holding1, 3, 6, 12 (months)
lag0, 1 (months of implementation lag)
return_typeexcess, total
date, retend of the return month, decimal monthly return

Example in Python

import pandas as pd

url = "https://zenodo.org/records/24113425/files/factor_returns.csv?download=1"
fr = pd.read_csv(url, parse_dates=["date"])

momentum = fr.query("factor == 'momentum' and portfolio == 'LS' and weighting == 'ew' "
                    "and holding == 6 and lag == 0 and return_type == 'excess'")
print(momentum.set_index("date")["ret"].describe())

How to cite

Please cite the methods paper:

Mählmann, T. (2026). Leveraged Loan Factors from Public Data. Working paper, SSRN. https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7704758

and the data release you use:

Mählmann, T. (2026). Leveraged Loan Factors (Version 2026.11) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.24113425

The DOI 10.5281/zenodo.24113424 refers to all versions and always resolves to the latest release. If you use or adapt the pipeline, please also cite the software:

Mählmann, T. (2026). Leveraged Loan Factors (Version v2026.12) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.24114955
